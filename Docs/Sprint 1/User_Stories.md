# User Stories
## AI-generated stories
1. As a job seeker, I want to receive reminders before a saved job’s application deadline so that I do not miss an opportunity I intended to apply for.
2. As a job seeker, I want to maintain a daily job-search streak by completing at least one meaningful activity each day so that I remain consistent and motivated throughout my job search.
3. As a job seeker, I want to search and filter job postings by keywords, location, and job type so that I can find jobs that match what I am looking for.
4. As a job seeker, I want to save job postings that interest me so that I can easily find and review them later.
5. As a job seeker, I want to track the status of my job applications so that I can stay organized and know where each application stands.
6. As a job seeker, I want to practice interview questions through a mock interview so that I can feel more prepared for real interviews.
7. As a job seeker, I want to update my skills, education, and work experience so that my profile shows my current qualifications.
8. As a recruiter, I want to create a job posting with information about the position so that job seekers can find and apply for it.
9. As a recruiter, I want to view the job seekers who applied to my job posting so that I can review their profiles and resumes.
10. As a recruiter, I want to update an applicant’s application status so that they can see the progress of their application.

## Team-generated user stories
1. As a job seeker or recruiter, I want to create an account using my email address and password so that I can securely access CareerConnect’s features.
2. As a user, I want to log in to my account so that I can access my CareerConnect profile and features.
3. As a job seeker, I want to upload a resume to my profile so that I can store it on CareerConnect and use it when applying for jobs.
4. As a job seeker, I want to compare multiple job postings side by side so that I can easily compare their salaries, requirements, locations, and benefits.
5. As a job seeker, I want to see how long each of my applications has been in its current status so that I can identify applications that have not been updated for a long time.
