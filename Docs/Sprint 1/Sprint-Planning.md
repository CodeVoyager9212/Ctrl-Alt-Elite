# Sprint 1 Planning
## Sprint Goal
The goal of Sprint 1 is to set up the CareerConnect project, organize the team's work, define the main requirements and user stories, and begin developing the basic features of the platform.

For development, the team will focus on user registration, login, profile management, resume management, and the general website interface.

## Sprint Backlog
- Set up and organize the GitHub repository.
- Complete the required Sprint 1 documentation.
- Create and organize the CareerConnect user stories and tasks.
- Develop the first basic features of CareerConnect.
- Test and review the completed work before submission.

## Priorities
- **High:** GitHub setup, Sprint 1 documentation, user stories, user registration and login, profile management, and resume upload.
- **Medium:** General website UI and improvements to the basic features.
- **Low:** Additional features that are planned for CareerConnect but are not required to be developed during Sprint 1.

## Effort Estimation
The team uses three levels to estimate the effort needed for each task:
- **Low:** Small tasks that can be completed quickly.
- **Medium:** Tasks that require more development, testing, or coordination.
- **High:** Larger tasks that require more time and several development steps.

## Team Capacity
The team has six members. For Sprint 1 development, the team is divided into three groups:
- **Philopater & Peter:** User registration, authentication, and profile management.
- **Anas & Omar:** Resume upload and management.
- **Arman & Alfred:** General website UI, excluding the profile page.

Team members also contribute to planning, documentation, testing, and reviewing the project.

## Risks
- Some features may take longer to develop or test than expected.
- Changes from different team members may cause conflicts when combining code.
- Team members may have different availability during the sprint.
- Bugs or technical problems may delay some features.
- Some requirements may need changes after team discussions or testing.
