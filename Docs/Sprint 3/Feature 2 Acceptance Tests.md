# Feature 2 acceptance tests

Run these scenarios against the team's Supabase project using test accounts. Open the job seeker's Dashboard after preparing the application records.

| User story | Setup and action | Expected result |
|---|---|---|
| As a job seeker, I want to see my previous applications so I can track where I applied. | Give the job seeker two applications with different submission dates. Give a second job seeker a separate application. Sign in as the first job seeker and open Dashboard. | Only the first job seeker's two applications appear, newest first, with job details, submission dates, and current statuses. Detailed tracking opens My Applications. |
| As a job seeker, I want to see how my applications are distributed across statuses so I can understand my pipeline. | Prepare five applications, two Applied, one Under Review, one Interview, and one Rejected. Open Dashboard. Expand and collapse Active Applications and Decided Applications independently. Select Applied in the chart legend and switch from Count to Percentage. Have the recruiter change Interview to Offered, then reopen Dashboard and select each of those statuses. | Total Applications shows five, Active Applications shows four, and Decided Applications shows one. Active expands to Applied, Under Review, and Interview. Decided expands to Offered and Rejected. The Applied chart reading switches from two applications to 40%. After the recruiter update, Total Applications stays at five, Active drops to three, and Decided rises to two. Interview shows zero, Offered shows one, and the pie and history badge update. |
| As a job seeker, I want to change the chart's time scale so I can review both recent and older submissions. | Use sample submissions on different days, weeks, months, and years. Open Dashboard and select each time scale. Select Previous when older submissions exist, then select Next. | The chart groups submissions by the chosen scale in local time, with weeks starting Monday. Previous and Next show adjacent date ranges. The date label, bar counts, and period total match the selected range. History and current status totals remain consistent. |
